<h1 align="center">UsageTrackerWidget</h1>

<p align="center">
  A Windows widget that shows how much of your AI service usage limits remain.
</p>

UsageTrackerWidget sits on or near the Windows taskbar and shows the percent used and time until reset for each of your AI usage windows. It starts with Codex: the 5-hour and weekly windows, plus the separate daily image-generation allowance that no official usage page shows.

## Status

Early planning. There is no application code yet; the stack and design are still being decided. See [VISION.md](VISION.md) for direction and [docs/codex-usage-sources.md](docs/codex-usage-sources.md) for how Codex usage data can be read.
